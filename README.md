RETAIL COMPETITIVE ANALYSIS
Product Scent & Packaging Strategy – GELFRESH

Descripción del Proyecto

Este proyecto desarrolla un análisis competitivo en el sector retail, enfocado en evaluar estrategias de aroma (scent) y empaque (packaging) para la marca GELFRESH.
El objetivo principal es transformar datos crudos de un estudio de mercado en información estratégica que permita:
Identificar oportunidades frente a competidores.
Analizar tendencias de preferencias de aroma.
Evaluar percepción del consumidor sobre empaques.
Detectar patrones de precio en el mercado.
Apoyar la toma de decisiones comerciales y de posicionamiento.

🎯 Objetivos del Análisis

🧹 Realizar limpieza y preparación de datos.
📊 Analizar distribución de precios en el mercado.
🌿 Evaluar popularidad y frecuencia de aromas.
📦 Analizar tipos de empaque más utilizados.
🏷 Comparar posicionamiento competitivo.
📈 Generar insights accionables para estrategia comercial.


⚙️ Tecnologías Utilizadas

Python 3
Pandas
NumPy
Jupyter Notebook
OpenPyXL (para lectura de Excel)

🧹 Proceso de Data Cleaning

El notebook 01_data_cleaning.ipynb incluye:

1️⃣ Carga e inspección inicial

Revisión de estructura del dataset.
Identificación de tipos de variables.
Análisis preliminar de valores nulos.

2️⃣ Estandarización

Normalización de nombres de columnas.
Conversión de texto a formato consistente.
Eliminación de espacios y caracteres innecesarios.

3️⃣ Tratamiento de valores faltantes

Identificación de campos críticos.
Evaluación del impacto en variables como:
Precio
Aroma
Tipo de empaque

4️⃣ Dataset listo para análisis

El resultado es una base limpia y estructurada para:

Análisis exploratorio (EDA)
Visualización
Modelos predictivos
Dashboard en herramientas BI

📊 Posibles Aplicaciones Estratégicas

Los insights obtenidos pueden utilizarse para:
Definir nuevos aromas prioritarios.
Ajustar estrategia de pricing.
Optimizar diseño y formato de empaque.
Identificar brechas frente a competidores.
Desarrollar estrategia de posicionamiento retail.
